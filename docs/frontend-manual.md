# 大肥鱼设置面板操作手册

## 1. 文档说明

本手册介绍「大肥鱼」插件的设置界面（以下简称「面板」）的使用方法，包括插件原有的各项设置，以及新增的小智 ESP32 语音终端通道与云端语音服务配置。

手册只说明界面操作，不涉及安装部署与固件烧录。设备端的部署与日常使用，请参阅《小智 ESP32 语音终端操作手册》（`docs/esp32-channel-manual.md`）。

安全约定：本手册不包含任何真实的接口密钥、令牌或口令。密钥只应填写在面板的密钥输入框中，请勿截图外传，也不要写入公开文档。

## 2. 进入面板

### 2.1 主入口

打开 DeepSeek Harness 桌面端，进入「设置」，在左侧栏选择「大肥鱼」。该入口功能最完整，本手册以此为准。

### 2.2 辅助入口

插件同时提供一个独立的精简设置页，仅限本机浏览器访问，地址路径为 `/dsh-feiyu/`。该页面端口由桌面端自动分配，不便查找时，请直接使用主入口。精简页包含平台开关、主人、大脑、音色、作息、角色设定、记忆库与 ESP32 通道，不含抖音、B站、微信、自由行动等细项。

## 3. 使用须知

### 3.1 保存方式

面板没有统一的「保存」按钮，不同控件的保存时机如下：

| 控件类型 | 保存时机 |
| --- | --- |
| 开关 | 点击后立即保存 |
| 文本框、数字框 | 修改后点击框外空白处（失去焦点）时保存 |
| 下拉选择 | 选定后立即保存 |
| 密钥输入框 | 需点击旁边的「保存 Key」按钮 |
| 云端语音服务（见第 8 章） | 点击「测试连接」或「仅保存」时保存 |

保存成功后，界面底部会短暂出现提示。若提示保存失败，请先核对输入内容，再重试。

### 3.2 生效时间

不同设置的生效时间不同，面板在保存时会给出提示，大致规则如下：

- 大脑（对话模型）：下一次对话生效。
- 音色：更换后建议重启桌面端。
- 作息、抖音、B站的各项设置：下一次醒来或重启后生效。
- 微信的节奏设置：需点击「运行状态」中的「重启 QQ / 微信」。
- 平台开关：见第 5 章。

### 3.3 密钥的处理

- 所有密钥输入框保存后都不会回显，仅显示「已配置」或「已保存」。
- 密钥框留空表示「保持原有密钥不变」，不会清除。
- 如需更换密钥，直接输入新密钥并保存即可。

## 4. 运行状态

位于面板顶部，用于确认插件是否正常工作。

### 4.1 状态指标

| 指标 | 含义 |
| --- | --- |
| 生物钟 | 定时醒来功能是否在运行 |
| 今日评论 | 今天已发出的评论数量 |
| 今日分享 | 今天已分享的数量及上限 |
| 情绪、饿 | 她当前的情绪值与饥饿程度，会随时间自然变化 |
| 唱歌音色 | 唱歌所用的音色，与说话音色相互独立 |
| 干跑 | 当前处于「只演练」还是「真实发送」状态 |
| QQ 网关、QQ 进程、微信 | 各通道的连接情况，红色表示异常 |

### 4.2 干跑总闸

「干跑（总闸）」开关控制所有对外动作是否真正发送。

- 开启：她照常思考、记录，但弹幕、动态、点赞、评论、群聊、说说等一律只演练、不发送。
- 关闭：以上动作真实发出。

注意：关闭前请确认账号设置无误。该开关不影响抖音单独的演练开关。

### 4.3 常用操作

- 「刷新」：重新读取最新状态。
- 「跑一次体检」：对主要依赖项做一次检查，结果以对勾与叉号逐项列出，叉号项需要处理。
- 「重启 QQ / 微信」：重启这两个通道的后台服务。
- 「安装并启动 QQ 网关」：仅在 QQ 网关断开时出现。点击后系统会弹出一次管理员授权，选择「是」即可。若网关正等待扫码登录，则按钮显示为「重新拉网关」，并提示二维码图片的存放位置，请使用手机 QQ 扫描。

## 5. 平台开关

控制四个平台是否启用：B站、QQ、微信、抖音。

- QQ、微信、抖音私信默认不随桌面端自动启动。点开开关才会启动对应服务，桌面端退出后自动复位。
- B站依靠定时作息运行，开关改动后立即生效。
- 关闭的平台不会启动，也不会产生任何动作。

小智 ESP32 通道不在此处开关，见第 8 章。

## 6. 通用设置

### 6.1 主人

填写主人的身份信息，使她能够识别主人，并对其他人保持距离、不透露隐私。

| 项目 | 说明 |
| --- | --- |
| QQ 号 | 主人的 QQ 号码 |
| 称呼 | 她对主人的称呼 |
| B站 mid | 主人的 B站数字账号 |
| 微信 wxid | 可选，主人的微信标识 |
| 抖音昵称 | 分享内容时发送私信的对象 |

### 6.2 大脑（对话模型）

所有平台共用同一个对话模型，包括 ESP32 通道。

| 项目 | 说明 |
| --- | --- |
| API Key | 对话模型的访问密钥；填写后点击「保存 Key」 |
| 接口地址 | 对话模型服务的地址，例如 `https://api.deepseek.com/v1` |
| 模型 | 使用的模型名称，例如 `deepseek-chat` |

说明：若电脑上已设置环境变量 `DEEPSEEK_API_KEY` 或 `LLM_API_KEY`，则环境变量优先于此处的密钥。

### 6.3 音色

用于 QQ 与微信的语音回复，以及唱歌功能。

| 项目 | 说明 |
| --- | --- |
| 当前音色 | 从本机已有的音色中选择。选项后标注「缺参考文本」的，需补齐对应文本文件后才能正常使用 |
| 语音概率 | 0 至 1 之间的数值，表示每条回复改用语音发送的概率，0.5 即约一半 |
| 试听 | 合成一段语音并发送到 QQ，请在手机上查看 |
| 表情包概率 | 0 至 1，回复时附带图片表情的概率 |
| 全部音色试听 | 依次试听所有已有音色 |
| 让她唱一首 | 让她写词并演唱，完成后发送到 QQ |
| 主动搭话 | 开启后，安静一段时间她会主动联系；可设每日上限与两次之间的最小间隔（分钟） |
| AI 表情包 | 开启后，图库中没有的表情由她现场绘制并入库 |

新增音色需将参考音频与参考文本放入本机语音合成服务的音色目录，面板的提示文字中给出了目录位置。

### 6.4 作息与限额

B站与抖音共用同一个作息窗口。

| 项目 | 说明 |
| --- | --- |
| 醒来窗口 | 每天在该时间段内随机选择时间醒来，不会整点触发 |
| 醒来次数 | 窗口内醒来的次数 |
| 观看日报 | 汇总当天看过的内容，不调用对话模型 |
| 复盘学习日记 | 由对话模型提炼当天所看内容，追加到私人日记 |

### 6.5 角色设定

文本框中是她的人格底稿。她每次醒来都会读取，修改后她会按新的设定行事。修改后点击「保存角色设定」。

### 6.6 记忆库

显示她最近的对话片段，并统计对话、世界设定与主人事实的条数。点击「刷新」可重新读取。该区域只用于查看。

## 7. 平台专项设置

以下各项仅在主入口提供。

### 7.1 微信

| 项目 | 说明 |
| --- | --- |
| 节奏档位 | 控制两条消息之间的最小间隔：快（约 1.5 秒，推荐）、秒回（无节流，被平台限制的风险较高）、稳（4 至 7 秒）、很慢（适合长时间挂机） |
| 合并窗口 | 对方发完消息后等待的秒数；期间对方继续发送则继续等待，最长约 12 秒 |
| 上下文条数 | 回复时参考的历史消息条数 |
| 自己判断该不该接 | 开启后她先判断是否需要回复；关闭则每条都回 |

微信设置改动后，需点击「重启 QQ / 微信」生效。

### 7.2 抖音

默认所有对外动作关闭，请按需开启。

| 项目 | 说明 |
| --- | --- |
| 自主观看 | 点击「开始看」，后台浏览约 10 分钟 |
| 静默模式 | 后台运行，不弹出浏览器窗口 |
| 分享给主人 | 通过私信向主人发送视频链接及她的评论 |
| 自主评论 | 自主发表评论；需同时关闭抖音的演练开关才会真实发送 |
| 私信陪聊 | 持续关注主人的私信并自动回复 |
| 随 DSH 自启 | 关闭时，桌面端重启后私信陪聊会被自动关掉 |
| 评论 @ 通知 | 评论中带 @ 容易触发平台限制，默认关闭 |
| 每次条数、分享上限 | 每轮浏览条数与每天分享上限，0 表示不限 |
| 自由刷及其下属项 | 开启后持续浏览；可设为不限量，或限定最大条数与最长时长（分钟） |

### 7.3 B站

| 项目 | 说明 |
| --- | --- |
| 分享（@ 你） | 评分达到设定值时在评论区提及主人 |
| 每天分享上限 | 一天最多提及的次数，0 表示不限 |
| 静默自助刷 | 自主浏览、阅读并评论 |
| 自由刷及其下属项 | 与抖音同理 |
| 弹幕、动态、点赞、投币 | 各自设有每日数量上限，0 表示不限。投币涉及真实花费，请谨慎设置 |
| 图片评论、回评论 | 每日数量上限 |
| 鱼圈社交、关注 UP | 分别控制与同类账号互动及自动关注 |

### 7.4 自由行动

| 项目 | 说明 |
| --- | --- |
| 完全自由 | 总开关。开启后她按自己的节奏醒来，自主决定做什么，也可以选择休息。作品量、评论量、分享量仍受额度限制，微信不受影响。桌面端重启后该开关自动关闭 |
| 自由上网 | 允许她自行上网浏览、阅读、创作；可设每轮之间的休息分钟数。活动记录可在其日志文件中查看 |
| 自我升级 | 允许她修改自己的程序；系统会先备份并经测试，同时留有日志 |
| 人格进化 | 每隔设定的天数复盘一次，并更新角色设定中的自我迭代部分 |

自由上网与人格进化需重启桌面端后生效。开启前请先确认已了解其行为范围。

## 8. 小智 ESP32 通道

本章为新增功能，用于查看语音终端的接入状态，并配置语音识别与语音合成所使用的服务。

### 8.1 启用通道

通道的启用与端口设置位于配置文件 `feiyu.config.json` 的 `esp32` 段，面板不提供开关。若面板提示「ESP32 通道未启用」，请将 `esp32.enabled` 设为 `true`，然后重启桌面端。若提示「已启用但网关没在跑」，请检查端口是否被其他程序占用。

### 8.2 状态区

点击「刷新」可更新全部内容。

| 项目 | 说明 |
| --- | --- |
| 通道、网关、ASR、Token | 依次表示通道是否启用、接入服务是否运行、语音识别是否可用、接入令牌是否已设置。令牌只显示「已配置」或「未配置」，不显示内容 |
| 监听地址 | 设备连接电脑所用的地址 |
| OTA 地址 | 设备首次联网时访问的地址，点击「复制」可复制到剪贴板 |
| 生效服务 | 当前实际使用的语音识别与语音合成服务，以及兜底服务。若出现「已降级」提示，其后会说明原因 |
| 在线设备 | 已连接设备的标识、状态和最后活动时间 |
| 耗时 | 最近一轮对话各环节耗时，依次为静音判断、识别、对话首字、合成首帧和总耗时 |
| 最近对话 | 该设备最近的对话记录 |
| 最近错误 | 最近一次出错的原因，已隐去敏感信息 |

### 8.3 云端语音服务设置

默认使用本机的语音识别与语音合成。如需改用云端服务，可在「语音识别」和「语音合成」两个区域分别设置，两者互不影响。

#### 8.3.1 可选的服务

| 类别 | 服务 | 说明 |
| --- | --- | --- |
| 语音识别 | 本地 SenseVoice | 默认，无需配置 |
| 语音识别 | OpenAI 兼容云服务 | 适用于多数厂商，可选预设 |
| 语音识别 | 火山豆包语音 | 火山引擎的识别服务 |
| 语音合成 | 本地 GPT-SoVITS（句级、流式） | 默认，无需配置 |
| 语音合成 | OpenAI 兼容云服务 | 适用于多数厂商，可选预设 |
| 语音合成 | 火山豆包语音（流式） | 火山引擎的合成服务，边合成边播放，首句响应更快 |

选择本地服务时，界面提示「本地服务无需配置」。

#### 8.3.2 操作步骤

1. 在「服务商」下拉框选择要使用的云端服务。
2. 若所选为「OpenAI 兼容云服务」，可在旁边的下拉框选择预设（识别：SiliconFlow、Groq、OpenAI、自建 whisper；合成：SiliconFlow、OpenAI），系统会自动填入接口地址与模型名，之后仍可修改。
3. 填写各项参数，带 `*` 的为必填项。
4. 保持「通过后自动启用为主」处于开启状态，点击「测试连接」。
5. 查看测试结果：
   - 绿色并显示「连接成功」及耗时：测试通过。若已开启自动启用，该云端服务会成为主用服务，本地服务自动成为兜底，上方「生效服务」同步更新。
   - 红色并显示失败原因：配置未被改动，请按提示修正后重试。
6. 如只想保存参数、暂不切换主用服务，点击「仅保存」，此时不会进行测试。

测试内容：识别服务发送一段 1 秒的静音音频；合成服务合成一句「你好」，并显示首包耗时。

#### 8.3.3 参数说明

**OpenAI 兼容云服务（识别与合成通用）**

| 参数 | 说明 |
| --- | --- |
| 接口地址 | 厂商提供的服务地址，通常以 `/v1` 结尾 |
| API Key | 访问密钥，保存后不再显示 |
| 模型 | 厂商提供的模型名称 |
| 音色（仅合成） | 厂商提供的音色名称 |
| 语言（仅识别）、语速（仅合成）、超时 | 可选，一般保持默认 |

**火山豆包语音：语音识别**

| 参数 | 说明 |
| --- | --- |
| API Key | 在火山引擎控制台获取的访问密钥 |
| 资源 ID | 须与账号已开通的服务一致。默认值为极速版 `volc.bigasr.auc_turbo`；若账号开通的是其他型号，请按控制台中显示的资源 ID 填写 |
| 模型名、接口地址、超时 | 可选，一般保持默认 |

**火山豆包语音：语音合成**

| 参数 | 说明 |
| --- | --- |
| API Key | 与识别可使用同一个密钥 |
| 资源 ID | 默认 `seed-tts-2.0`，只能搭配 2.0 版音色；`seed-tts-1.0` 只能搭配 1.0 版音色。两者必须一致，否则测试会失败 |
| 音色 | 必须填写完整的音色编号，不能只填简称。2.0 版音色的编号形如 `zh_female_vv_uranus_bigtts`。该音色须已在您的账号中开通 |
| 语速、音量 | 取值范围 -50 至 100，默认 0 |
| 首包超时 | 默认 10 秒。网络较慢时可适当调大 |
| 块间超时、接口地址 | 可选，一般保持默认 |

#### 8.3.4 注意事项

- 密钥框留空表示沿用已保存的密钥。
- 云端服务出现故障时，系统会自动改用本地服务继续对话，不会中断。
- 更换服务商或修改参数后，建议再次点击「测试连接」确认可用。
- 若填写错误的密钥，测试会失败并给出原因；此前的配置保持不变。

## 9. 常见问题

| 现象 | 可能原因 | 处理方法 |
| --- | --- | --- |
| 面板显示「载入失败」 | 插件未加载，或不是从本机访问 | 确认桌面端已启动且插件已加载，然后点击「重试」 |
| 修改后似乎没有生效 | 该项需要下一次对话、醒来或重启后生效 | 参照第 3.2 节；必要时重启桌面端 |
| QQ 网关显示「断开」 | 网关未启动或需要重新登录 | 点击「安装并启动 QQ 网关」，按提示授权或扫码 |
| 微信状态显示「心跳停了」 | 微信服务未运行 | 点击「重启 QQ / 微信」 |
| 云端语音测试失败，提示未授权 | 密钥错误，或账号未开通对应服务 | 核对密钥与资源 ID，并在服务商控制台确认已开通 |
| 云端语音合成测试失败，提示服务端错误 | 音色编号不完整，或音色与资源 ID 版本不匹配 | 填写完整的音色编号，并使资源 ID 与音色版本一致 |
| 云端语音测试超时 | 网络较慢 | 调大超时参数，或稍后重试 |
| 「生效服务」出现「已降级」 | 主用云端服务无法使用，已自动改用本地服务 | 查看降级原因，修正配置后重新测试 |
| 设备数量为 0 | 设备未联网，或固件中的地址已过期 | 参阅《小智 ESP32 语音终端操作手册》的故障排查章节 |
