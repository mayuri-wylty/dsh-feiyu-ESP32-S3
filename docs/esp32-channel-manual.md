# 小智 ESP32 语音终端操作手册

## 1. 文档说明

本手册面向使用本机 DeepSeek Harness 桌面版（以下简称「桌面端」）与 dsh-feiyu 插件（以下简称「插件」），通过 ESP32-S3 语音终端（以下简称「设备」）与大肥鱼对话的用户。

手册覆盖二次开发新增的 ESP32 通道，内容包括部署、日常使用、状态查看、配置与故障处理。插件原有功能不在本手册范围内。

安全约定：本手册不包含任何真实令牌、接口密钥或无线网络口令。实际值仅保存在本机配置文件中，请勿写入仓库、截图或公开文档。

## 2. 系统构成

| 组成部分 | 作用 | 运行位置 |
| --- | --- | --- |
| 设备 | 采集语音、播放回复、显示对话气泡与表情 | ESP32-S3 板端 |
| 桌面端与插件 | 提供设备接入服务，串联识别、对话与合成 | 本机 |
| 语音识别 | 将设备上传的语音转为文字 | 本机（可选云端备选） |
| 对话与记忆 | 沿用大肥鱼的人格、情绪与共享记忆 | 本机 |
| 语音合成 | 将回复合成为语音 | 本机（可选云端备选） |

设备不直接连接外部服务，全部语音数据经本机处理。板上的对话会写入大肥鱼的共享记忆，其他通道可以引用。

## 3. 使用前提

- 硬件：ESP32-S3 主控（8MB PSRAM、16MB Flash）、ST7735 128×160 显示屏、麦克风与扬声器、USB 数据线。
- 软件：Windows 10/11；DeepSeek Harness 桌面版；dsh-feiyu 插件；桌面端语音输入组件及其中文识别模型；GPT-SoVITS 本地语音合成服务；ESP-IDF 6.0.1（仅在构建固件时需要）。
- 网络：设备与电脑处于同一局域网。固件中写入了电脑的局域网地址，建议在路由器上为本机保留固定地址，避免地址变化后设备无法连接。

## 4. 首次部署

### 4.1 启动桌面端

```powershell
pwsh -File D:\AI_Code\小智机器人\dsh-feiyu\scripts-esp32\start-dsh.ps1
```

脚本会启动桌面端并等待其就绪；若已在运行，则直接报告状态。桌面端内部端口由程序动态分配，无需手动指定。

### 4.2 安装并启用插件

首次部署时执行一次：

```powershell
dsh plugin --profile desktop add "link:D:\AI_Code\小智机器人\dsh-feiyu"
```

随后在桌面端的插件页面启用语音输入组件，并等待中文识别模型下载完成。

### 4.3 启动语音合成服务

```powershell
pwsh -File D:\AI_Code\小智机器人\dsh-feiyu\scripts-esp32\start-sovits.ps1
```

服务默认监听本机 9880 端口。首次启动需要加载模型，通常耗时数十秒。参考音频与对应文本需提前放入 GPT-SoVITS 的模型目录。

### 4.4 环境自检

```powershell
pwsh -File D:\AI_Code\小智机器人\dsh-feiyu\scripts-esp32\probe.ps1
```

脚本依次检查桌面端是否在线、插件是否已加载、语音合成服务能否完成一次真实合成。退出码含义：0 表示全部通过，1 表示存在失败项，2 表示存在需要人工处理的项。

### 4.5 构建与烧录固件

前提：已安装并激活 ESP-IDF；固件源码位于纯英文路径下（当前为 `D:\esp32\xiaozhi-esp32`）。

```powershell
python D:\AI_Code\小智机器人\dsh-feiyu\scripts-esp32\build-firmware.py
pwsh -File D:\AI_Code\小智机器人\dsh-feiyu\scripts-esp32\flash-firmware.ps1 -Port COM3 -Baud 230400
```

注意事项：

- 本机面板为 ST7735 128×160。板卡预设按 240×320 配置，直接按预设构建会导致花屏。构建脚本会自动改为正确型号，请勿手动执行通用构建命令后烧录。
- 构建脚本同时写入本机局域网地址与自定义唤醒词「大肥鱼」，无需另行修改源码或配置界面。
- 烧录按分区逐个写入，保留设备中已保存的无线网络配置。请勿烧录整片合并镜像，否则会清除配网信息。
- 烧录波特率建议使用 230400；使用 460800 可能中途断开。
- 更换电脑或本机局域网地址发生变化后，需重新构建并烧录固件。

### 4.6 设备联网与接入

首次使用时，在设备启动阶段短按 BOOT 键进入配网模式，按屏幕提示连接设备热点并填写无线网络信息。

联网后接入过程自动完成：设备向电脑请求接入地址，获得地址与访问令牌后建立连接。设备上无需手动输入地址或令牌。

验证方式：桌面端设置页的「小智 ESP32 通道」卡片显示「网关运行中」，且在线设备数不少于 1。

## 5. 日常使用

### 5.1 唤醒

对设备说「大肥鱼」。唤醒后设备播放一句简短问候，默认从「我在呢」「嗯？怎么啦」中随机选择，随后进入聆听状态。

也可以短按 BOOT 键直接开始一轮对话。

### 5.2 对话

说完后停顿约 0.7 秒，设备自动结束录音并开始处理。回复以语音播放，屏幕同时以气泡形式显示双方文字。单句语音最长约 30 秒。

### 5.3 连续对话

一轮回复结束后，设备自动回到聆听状态，可直接继续说话，无需再次唤醒。长时间没有语音输入时，设备会自动结束本次会话。

### 5.4 打断

设备播放回复期间，短按 BOOT 键可以立即中止当前回复；中止后可再次唤醒或按键开始新一轮对话。

本设备没有回声消除功能，播放期间麦克风不采集上行语音，唤醒词在播放期间不生效，因此不支持直接开口打断，打断统一使用 BOOT 键。

### 5.5 表情与指示灯

回复携带的情绪会映射为屏幕表情；无法识别的情绪显示为平静。板载指示灯与灯控接口按固件默认行为工作。

## 6. 查看运行状态

入口：桌面端「设置」→「🐟 大肥鱼」→「小智 ESP32 通道」。该卡片为只读展示，配置项需修改配置文件。

| 项目 | 含义 |
| --- | --- |
| 通道状态 | 通道是否已启用 |
| 网关状态 | 接入服务是否正在运行 |
| 语音识别 | 识别组件是否可用 |
| 令牌 | 是否已配置（只显示状态，不显示内容） |
| 在线设备 | 当前连接的设备数量 |
| 监听地址 | 接入服务在本机监听的地址 |
| 接入地址 | 设备启动时访问的地址，可一键复制 |
| 在线设备列表 | 设备标识、当前状态、最后活动时间 |
| 最近对话 | 最近几轮的用户语音文字与回复文字 |
| 耗时 | 语音结束检测、识别、首句生成、首句合成、整轮耗时 |
| 最近错误 | 最近一次失败的原因，敏感信息已隐藏 |

## 7. 配置说明

配置文件位于 `%USERPROFILE%\.dsh\feiyu.config.json`，ESP32 相关设置集中在 `esp32` 段。修改后需重启桌面端生效。

常用配置项：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 启用通道 | 是 | 关闭后接入服务不启动，设备无法连接 |
| 监听端口 | 8765 | 接入服务端口；修改后需同步更新固件中的地址并重新烧录 |
| 对外地址 | 空（自动选择） | 电脑存在多块网卡或虚拟网卡时，可手动指定局域网地址 |
| 允许设备 | 空（不限制） | 填写设备标识后，仅列表内的设备可以接入 |
| 工作模式 | 完整问答 | 可选「仅转写」与「回声」用于排查 |
| 静音判定时长 | 700 毫秒 | 说话停顿超过该时长即视为一句结束 |
| 语音识别方式 | 本地识别 | 可配置云端备选接口 |
| 语音合成方式 | 本地流式合成 | 可切换为逐句合成，或配置云端备选接口 |
| 唤醒问候语 | 「我在呢」「嗯？怎么啦」 | 可增删；留空则不播放问候 |
| 附加人格提示 | 空 | 补充语音场景下的表达要求 |
| 空闲断开 | 5 分钟 | 无音频超过该时长后自动断开设备连接 |

如需手动编辑，只需保留原有结构、修改对应项，例如：

```json
"esp32": {
  "enabled": true,
  "port": 8765,
  "publicHost": "",
  "pipeline": "qa"
}
```

工作模式说明：

- 完整问答：识别、对话、合成依次执行，为默认模式。
- 仅转写：只做语音识别，适合单独排查识别效果。
- 回声：将收到的声音原样回放，适合排查音频链路。

当语音识别或语音合成不可用时，系统会自动降级为回声模式，并在状态页与最近错误中提示。

## 8. 故障排查

| 现象 | 可能原因 | 处理方法 |
| --- | --- | --- |
| 屏幕花屏或出现雪花 | 面板型号配置错误 | 使用构建脚本重新构建并烧录；确认面板为 ST7735 128×160；不要按板卡预设或手动构建后烧录 |
| 说唤醒词没有反应 | 环境噪声、距离过远或唤醒阈值不合适 | 在安静环境中靠近麦克风清晰说出；用 BOOT 键确认设备其余功能正常；查看串口日志确认唤醒词已加载 |
| 状态页显示网关未运行 | 通道被关闭，或端口被其他程序占用 | 确认通道已启用；检查 8765 端口未被占用；重启桌面端 |
| 设备无法连接 | 本机地址变化、防火墙拦截，或设备保存的地址已过期 | 核对固件中的地址与当前局域网地址一致；为接入端口放行专用网络入站；地址变化后重新构建并烧录 |
| 有文字但没有声音 | 语音合成服务未启动，或参考音频缺失 | 启动合成服务并重新运行自检；查看最近错误；若已自动降级为回声，恢复合成服务后重启桌面端 |
| 状态页显示语音识别不可用 | 语音输入组件未启用，或模型尚未下载完成 | 在插件页面启用组件，等待模型下载完成；状态页会同步显示识别状态 |
| 唤醒后没有问候语 | 问候语为空，或首轮问候被随后的聆听请求取消 | 属于正常设计；需要问候时可恢复默认文本 |
| 回答明显延迟 | 合成模型首次加载、内存紧张或存在并发占用 | 等待模型加载完成；关闭不必要的程序；避免同时使用多个语音通道 |
| 连接一段时间后自动断开 | 空闲断开机制 | 属于正常行为；重新唤醒即可 |
| 烧录中途失败 | 波特率过高或 USB 连接不稳定 | 改用 230400 波特率；更换数据线或 USB 接口 |
| 构建失败并提示路径问题 | 构建路径包含中文字符 | 使用纯英文路径的固件副本，并在原生 PowerShell 中激活 ESP-IDF |

防火墙放行命令（需在管理员 PowerShell 中执行一次）：

```powershell
New-NetFirewallRule -DisplayName "feiyu-esp32" -Direction Inbound -Protocol TCP -LocalPort 8765 -Profile Private -Action Allow
```

## 9. 安全与维护

- 访问令牌：首次启动时自动生成，仅保存在本机配置文件；设备通过接入流程自动获取。设置页只显示是否已配置。请勿复制、截图或提交到仓库。
- 接口密钥：云端识别与合成所用的密钥同样只保存在本机配置文件，不得写入公开文档。
- 无线网络：设备配网信息保存在板端，不写入仓库。
- 防火墙：仅对专用网络放行接入端口，不建议对公用网络开放。
- 日志：串口日志与构建日志位于 `scripts-esp32` 目录，可能包含网络名称与局域网地址，已被版本管理忽略，请勿手动提交。
- 重启生效：插件不支持热更新，修改配置或插件代码后需重启桌面端。
- 升级：插件以链接方式安装，更新源码后重启桌面端即可；固件升级需重新构建并烧录。
- 数据备份：对话记忆保存在 `%USERPROFILE%\.feiyu-ai\`，可整体备份；配置文件中含访问令牌，备份时请单独处理，避免随记忆目录一起公开。
