# 大肥鱼 AI 虚拟角色：小智 ESP32-S3 语音终端 + 多平台陪伴机器人

## 项目说明

本仓库基于 [baishuyue/dsh-feiyu](https://github.com/baishuyue/dsh-feiyu)（v0.4.0）进行二次开发。上游项目的原有代码、角色设定与设计版权归原作者所有。

在上游功能的基础上，本仓库主要完成了以下工作：

- 新增**小智 ESP32-S3 语音终端**通道，使角色可以通过实体硬件进行语音对话；
- 接入火山引擎云端语音识别与语音合成，作为本地语音服务的补充与备用；
- 新增“连接中心”，统一管理各平台的登录与连接状态；
- 重构设置面板，界面更简洁、操作更集中；
- 完善依赖安装脚本、部署与复现文档，以及硬件说明。

详细的版本变化请参阅文末的[更新日志](#更新日志)。

## 一、项目简介

大肥鱼是一个运行在本机、以 DSH 桌面端插件形式工作的虚拟角色。她拥有固定的人格、情绪与作息，并在多个平台上以同一身份活动：

| 平台 | 主要能力 |
|---|---|
| 哔哩哔哩 | 按作息自主浏览视频、撰写评论与日记、维护自己作品下的评论区 |
| QQ | 实时私聊与群聊回复，支持语音消息、表情图片与空间动态 |
| 微信 | 代替主人回复消息，按联系人分别记忆 |
| 抖音 | 自主观看、评论互动、作品评论区维护与私信陪聊 |
| 小智 ESP32（本仓库新增） | 通过实体语音终端进行唤醒、对话与表情显示 |

各平台共用同一套人格、情绪与记忆。所有对外发布的行为默认关闭，并且每一项都设有独立开关与每日上限，可在 DSH 设置面板中统一管理。

## 二、核心设计

### 2.1 统一记忆

角色在不同平台上的对话彼此独立，但“说过的话”和“做过的事”统一记录、共同可见。因此，无论在哪个平台询问，她都能回忆起在其他平台发生的事情。微信属于代回消息的工作场景，其记录不进入角色的个人记忆。

记忆采用原文完整保存、按关键词检索的方式，不使用向量数据库。在当前数据规模下，这种方式更准确、也更易于排查问题。

### 2.2 时间感知

每一轮对话都会注入准确的当前时间及双方上一次发言的间隔，避免角色凭感觉编造“好几天没见”之类与事实不符的说法。

### 2.3 记忆与承诺管理（“脑”模块）

在原文记忆之上，项目增加了一层结构化的“脑”模块，主要保证以下几点：

- 回忆时能够给出依据，可追溯到原始记录；
- 角色答应要做的事情会被记录并按时执行，未完成会如实记为失败，不会被静默遗忘；
- 角色对自身的认知变化有历史版本，可以审计与回退。

该模块支持关闭、仅记录、正式启用三种模式，关闭后完全恢复原有行为。详细设计见 [FEIYU-BRAIN-PLAN.md](FEIYU-BRAIN-PLAN.md)。

### 2.4 自主生活

- **作息**：在设定的时间窗口内随机醒来，浏览内容、撰写日记；
- **自由时间**：开启后，角色会自行安排上网查阅、写作、看番、制作短视频等活动；
- **每日回顾**：每晚整理当日经历、更新日记与自我认知，修改前自动保存快照；
- **创作**：可生成固定形象的表情图片、使用克隆音色说话或翻唱，并制作带配音与字幕的短视频。短视频制作完成后需由主人手动确认发布。

### 2.5 安全边界

- 所有外发行为具有总开关、分平台开关、每日额度与内容相似度去重；
- 遇到平台风控或限流时自动暂停；
- 表情图片只使用基于参考图生成的固定形象，宁可退回文字表情，也不发送形象不符的图片；
- 主动搭话设有多重限制，原则是“宁可沉默，不刷屏”。

## 三、小智 ESP32 语音终端（本仓库新增）

### 3.1 功能概述

将一块运行小智固件的 ESP32-S3 开发板接入本插件后，用户可以通过唤醒词与角色进行语音对话：

1. 设备被唤醒后，角色先播放一句问候；
2. 用户说话，系统自动判断语句结束并进行语音识别；
3. 角色以同一套人格与记忆生成回复，逐句合成语音并下发播放；
4. 设备屏幕根据回复的情绪显示对应表情；
5. 对话内容写入共享记忆，在其他平台同样可以被回忆起来。

### 3.2 语音服务

| 环节 | 可选方案 |
|---|---|
| 语音识别 | 本地识别（默认）、OpenAI 兼容接口、火山引擎极速版 |
| 语音合成 | 本地 GPT-SoVITS 流式合成（默认）、逐句合成、通用云端接口、火山引擎流式合成 |

每个环节均可配置主用与备用方案，主用失败时自动切换。设置面板提供“测试连接”功能，测试通过后可自动设为主用。

### 3.3 使用限制

- 服务端在本机局域网内运行，设备与电脑需处于同一网络；更换网络后需要重新生成并烧录固件配置；
- 设备连接需要访问令牌，并可设置允许接入的设备白名单；
- 当前开发板没有回声消除功能，播放期间无法通过说话打断，只能使用唤醒词或板载按键打断；
- 首次使用需在 Windows 防火墙中放行对应端口。

## 四、安装与部署

### 4.1 安装插件

```powershell
dsh plugin --profile desktop add "link:C:\Users\<用户名>\.dsh\plugins\dsh-feiyu"
```

安装后需重启一次 DSH 桌面端。插件中的宿主部分代码修改后同样需要重启才能生效。

### 4.2 外部依赖

| 用途 | 依赖 |
|---|---|
| QQ | NapCat（独立运行版） |
| 语音 | GPT-SoVITS（本地）或火山引擎云服务 |
| 微信 | 微信 PC 客户端及其自动化组件 |
| 抖音 | 本地 Chrome 及其自动化组件 |
| 表情与配图 | 图像生成服务密钥及角色参考图 |
| ESP32 通道 | ESP-IDF 开发环境与开发板 |

`deps/` 目录提供一键安装脚本。完整的版本要求、安装顺序与验证方法见 [DEPLOY.md](DEPLOY.md)，在新机器上复现环境请参阅 [docs/REPRODUCE.md](docs/REPRODUCE.md)。

### 4.3 配置

- 配置文件：`~/.dsh/feiyu.config.json`，可在设置面板中修改，保存后立即生效，示例见 [feiyu.config.example.json](feiyu.config.example.json)；
- 哔哩哔哩凭据单独保存在 `~/.feiyu-ai/credentials.json`，不会在界面中回显；
- 角色记忆、日记与作品均保存在用户目录下，不纳入版本库。

## 五、设置面板

在 DSH 中打开“设置 → 大肥鱼”即可使用。面板主要包括：

| 区域 | 内容 |
|---|---|
| 顶部状态栏 | 各通道运行状态、当日计数、当前情绪与环境自检 |
| 连接中心 | 哔哩哔哩登录信息、抖音扫码登录、QQ 扫码登录及状态汇总 |
| 通道卡片 | 哔哩哔哩、QQ、微信、抖音、小智 ESP32 各自的开关与参数 |
| 大脑 | 对话模型的接口与密钥配置 |
| 通用与自由时间 | 作息、额度、自由活动等设置 |
| 角色与记忆 | 角色设定编辑、近期对话与记忆统计 |

具有风险的操作集中放置在各卡片的“危险区”中。面板操作说明见 [docs/frontend-manual.md](docs/frontend-manual.md)。

## 六、常见问题

| 现象 | 可能原因 |
|---|---|
| 角色长时间无动作 | 自由时间未抽中、模型额度不足，或会话未授予完整权限 |
| QQ 服务运行但不回复 | NapCat 未启动或未登录 |
| QQ 语音无声 | 本地语音服务未启动 |
| 哔哩哔哩评论失败 | 凭据不属于同一账号，或触发平台限流 |
| 抖音显示回复成功但不可见 | 新账号在他人作品下的回复被平台审核拦截 |
| ESP32 设备无法连接 | 设备与电脑不在同一网络、防火墙未放行，或令牌不一致 |
| ESP32 设备一直处于聆听状态 | 对话模型未配置或调用失败，请在“大脑”卡片中检查 |

更多排查方法见 [DEPLOY.md](DEPLOY.md) 与各平台文档。
